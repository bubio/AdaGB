# AdaGB

GAME BOY COLORエミュレーターの開発です。

Ada言語を用います。ツールはAlireです。

Ada言語を私が学習するための題材して取り組みます。

## 特徴

* CLIでもROMファイル、オプションを指定して起動可能
* 高速動作（処理負荷が軽い）

## UI

## 対応OS、アーキテクチャ

* macOS 13.5以上 (Xcode 27でビルドすることを想定) : x86_64, Appleシリコン

macOS版はユニバーサルではなく、別々のバイナリとする

## 技術スタック

* 言語はAdaを使用する。インストール済み。
* 描画、音声、入力はSDL2を使用
* SDL2はシステムにインストール済みのもの（macOSはHomebrew or MacPorts）に動的リンクする。
* SDL2の動作を確認したものは ~/dev/_Emu/_SandBox/ada_imgui_test　にある。

## 開発環境

* Visual Studio Code


## コマンドラインオプション

```shell
adagb [options] game.gbc
````

-h, --help　: コマンドラインの使い方を表示
-v, --version : バージョンを表示

## 設定ファイルの場所

* `~/Library/Application Support/AdaGB/` とする
* 起動時に設定ファイルがなければ、すべてデフォルト値で作成する

## セーブ、ステートファイルの場所

* セーブファイルは設定ファイルと同じ場所とする

## CI/CD

* GitHubのworkflowによって行う。例えばビルドならビルドに必要なファイルが更新された場合に発動するようにすること。
* 開発時は、簡単にビルドができるよう、開発環境にあったスクリプトを用意する（sh）
* CI/CDでも同じスクリプトを使用することで差異のないようにしたい
* 頒布する形式は全てのプラットフォームでzipファイルとし、この中に必要ならライセンスファイルも同梱する

## ライセンス

* MITのようなゆるいライセンスとしたい


## 対応しないこと

* 実BIOS ROMの読み込みには対応しない


## 注意事項

* 実際のユーザー名を記載することは絶対だめ。~ や環境変数を使うこと。
